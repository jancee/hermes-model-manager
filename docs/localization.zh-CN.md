# 本地化指南

[English](localization.md) | 简体中文

即使系统语言为中文，界面仍默认使用英文。用户可以通过侧栏或应用的 Language 菜单切换英文与简体中文。语言选择保存到本应用的 macOS 偏好；预览可以临时覆盖语言，而不保存选择。

## 资源

- `Resources/Locales/en.json`：作为基准的英文键和值。
- `Resources/Locales/zh-Hans.json`：相同的键与对应简体中文译文。
- `Sources/Localization.swift`：语言选择、资源加载、格式化和回退逻辑。

界面字符串使用 `L("English source text")`。动态值使用带编号的占位符，例如 `L("Add {0} models", count)`。译文可以调整占位符顺序，但必须保留编号。未知字符串回退为英文。端点名称、模型 ID、路径和其他用户输入值必须保持原样。

Python 适配程序返回基准英文消息。原生界面在显示时翻译已知消息和格式化模板，因此现有状态或错误消息可以随界面一起切换语言。应用不会对用户数据进行自由文本翻译。

## 更新字符串

1. 新增或修改英文源字符串，并更新两份 JSON 资源。
2. 保留占位符编号、换行和原意。统一使用 **endpoint / 端点**、**model / 模型** 和 **favorite / 收藏**。
3. 覆盖菜单、对话框、提示、校验消息和无障碍标签。
4. 使用项目 Python 运行 `scripts/check-localization.py`，并运行 `bash scripts/check-ui.sh`。
5. 检查两种语言的演示预览，确认没有裁切、异常换行或难以阅读的控件。

语言切换不能重新创建编辑器状态或清空选择。原生文本输入框在更新占位提示和无障碍标签时，应保留当前输入内容与光标位置。

添加其他语言时，需要新增 `AppLanguage` 枚举项和资源文件，为该语言扩展适配程序格式化消息的查找，并扩展资源一致性及行为检查。目前的动态模板查找支持英文和中文。

## Markdown 文档

`README.md` 和 `docs/` 下无语言后缀的文件使用英文作为默认语言。中文对应文件使用 `.zh-CN.md`，并在顶部互链。每次行为变化都应同步更新两个版本。许可证文本保留上游的权威原文。
