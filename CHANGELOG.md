# Changelog

English | [简体中文](CHANGELOG.zh-CN.md)

## 1.3.0 — 2026-11-11

Initial source publication of Hermes Model Studio in the `hermes-model-manager` repository.

### Added

- English as the default interface language, with a persistent English/Simplified Chinese selector in the sidebar and application menu.
- Shared language resources for views, menus, dialogs, accessibility labels, and adapter messages.
- Bilingual Markdown documentation, MIT licensing, and third-party license notices.
- Project-local Python setup, host-architecture build scripts, a single version source, and automated repository checks.

### Included from earlier local builds

- Custom endpoint CRUD, model editing, batch import/removal, fixed manual lists, and endpoint defaults.
- Shared Hermes favorites, visibility controls, and client reasoning presets.
- Header sorting for endpoint, model, and discovery lists with stable row selection.
- Cleanup of history-only models and management of manually configured IDs missing from the catalog.
- Native display-name entry that preserves trailing spaces and caret movement.
- Validation, reference checks, local backups, revision checks, and readback.

Earlier local builds were not GitHub releases; this changelog does not create historical release tags.
